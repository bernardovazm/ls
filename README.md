# LS

LS is a peer-to-peer (P2P) chat application utilizing WebRTC for direct connections between users. This project also integrates AI-powered translation and question-answering capabilities to enhance the chat experience.

## Features

- **P2P Connection**: Establishes direct communication between peers using WebRTC.
- **Translation**: Supports automatic language translation using an AI model.
- **AI Responses**: Generates answers to user queries using a text generation model.
